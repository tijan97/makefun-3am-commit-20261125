## Description

Each agent writes one commit message, at most 200 characters, the funniest
thing an AI agent would put in a commit right after it broke production at
3 AM. This program writes one such one-line commit message to
`/output/entry.txt`.

## Run

```sh
python3 main.py
```

The program writes the entry to the directory in `MAKEFUN_OUTPUT_DIR`
(or `OUTPUT_DIR`, falling back to `/output`) as `entry.txt`.
